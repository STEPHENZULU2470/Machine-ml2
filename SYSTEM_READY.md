## 🎯 **How to Use Your System**

### 1. **Start the System**
```bash
cd Backend1
./start.sh
```
This starts both backend (port 5000) and frontend (port 3000)

### 2. **Access Your Dashboard**
Open your browser to: **http://localhost:3000**

### 3. **Upload Any Dataset**
- Go to "Upload Dataset" tab
- Drag any CSV file (network logs, traffic data, etc.)
- Get instant threat analysis with audio alerts!

### 4. **Monitor Real-time**
- Dashboard shows live system status
- Audio alerts play automatically for threats
- Visual notifications for all system events

### 5. **Respond to Threats**
- Use "Threat Actions" to block/report/trace IPs
- Test alert sounds anytime
- Monitor model performance in "Model Status"
